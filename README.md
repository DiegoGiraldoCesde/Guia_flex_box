# Guías de consulta: Maquetación en CSS

Este repositorio reúne material de estudio y ejemplos prácticos sobre los fundamentos de distribución y posicionamiento de elementos en CSS.

## Contenido

- **Flexbox (`guia_flexbox.md`):** Guía completa sobre el modelo Flexible Box Layout, incluyendo contenedor e ítems flex, ejes principal y transversal, `flex-direction`, `flex-wrap`, `justify-content`, `align-items`, `align-content`, `order`, `align-self` y ejercicios propuestos.
- **Propiedad `display`:** Ejemplos prácticos sobre el comportamiento de los elementos en el flujo del documento (`block`, `inline`, `inline-block`, `none` y contenedores flex).
- **Propiedad `position`:** Ejemplos de posicionamiento en CSS (`static`, `relative`, `absolute`, `fixed` y `sticky`) junto con el uso de coordenadas y contexto de apilamiento.

## Cómo utilizar este material

1. Consulta los documentos en formato Markdown directamente desde GitHub para revisar la teoría y los diagramas.
2. Descarga o clona el repositorio para abrir los ejemplos de código en tu editor y experimentar modificando las propiedades CSS en el navegador.
